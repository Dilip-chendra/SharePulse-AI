# SharePulse-AI: Enterprise Revenue Recovery & Share-of-Wallet Platform

> **Synchrony Analytics Hackathon 2026** — Customer & Credit Card Analytics: Silent Attrition & Declining Share of Wallet.
> An enterprise-grade, data-driven revenue recovery decision platform for the **MetroMart Inc. × HSIC Bank** co-branded credit card partnership.

> **IMPORTANT GOVERNANCE & INTEGRITY NOTICE:**
> The numbers and analytical conclusions in this repository are validated working findings, reproduced independently by the application directly from the supplied CSV files before treating them as final. Zero analytical results are hardcoded. Statistical tests, multi-model benchmarks, and cluster validation curves are empirically derived.

---

## Executive Summary & Core Business Crisis
- **Dataset Universe:** 45,000 Customers (38,164 cardholders), 444,118 Transactions across 2 complete fiscal years (FY25: Aug 2024–Jul 2025, FY26: Aug 2025–Jul 2026).
- **The Core Problem:** HSIC Share of Wallet (SoW) collapsed from **28.91% in FY25 to 19.48% in FY26** (-9.43 percentage points / -32.6% relative collapse) despite total active customer spend at MetroMart expanding by +19.4% (₹296.3M to ₹353.8M).
- **Primary Leakage Sinks:** MetroMart Wallet captured **35.09%** of active spend (₹228.17M), and Cash/UPI surged by +8.02 pp (from 16.11% to 24.13%).
- **Financial Opportunity:** ₹70.5M in Revenue at Risk, ₹84.9M Recoverable Opportunity yielding ₹18.2M Expected Net Contribution at **3.65x Portfolio ROI**.

## 4-Tier Knowledge Taxonomy
- **OBSERVED:** Deterministic historical fact calculated directly from raw transaction/customer records.
- **MODEL_DERIVED:** Inference or prediction generated by machine learning models, clustering algorithms, or dimensionality reduction.
- **HYPOTHESIS:** Plausible behavioral, commercial, or UI friction mechanism explaining observed empirical patterns.
- **PROPOSED:** Actionable intervention, next best action playbook, or counterfactual policy recommendation.

## 🚀 Quick Start & Local Execution

### Prerequisites
- Python 3.10+ (Tested on Python 3.14)
- Node.js 18+ (Tested on Node.js v24.14.0)

### 1. Backend Setup & Pipeline Execution
```powershell
# Install Python dependencies
pip install -r requirements.txt

# Run the end-to-end analytical pipeline (builds SQLite database and cache.json)
python -m backend.analytics.pipeline

# Start FastAPI server on port 8000
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
```
API Documentation is live at `http://localhost:8000/docs`.

### 2. Frontend Setup & Launch
```powershell
# Navigate to frontend directory
cd frontend

# Install dependencies (if not already installed)
npm install

# Start development server on port 5173
npm run dev
```
Open `http://localhost:5173` in your browser.

### 3. Run Automated Tests
```powershell
# Run backend pytest suite (10 comprehensive tests)
python -m pytest tests/ -v

# Run frontend production build verification
cd frontend
npm run build
```

## 📊 Application Structure (14 Decision-Oriented Enterprise Pages)
1. **Executive Command Center:** Core portfolio KPIs, SoW contraction alert, revenue at risk, executive narrative.
2. **SoW Intelligence:** 24-month trend lines, velocity and acceleration, fiscal year comparison, Prime vs Non-Prime, Category matrix.
3. **Payment Migration:** Migration sankey/flow vectors, monthly payment shares, defector destination tracking.
4. **Attrition Radar:** 5 customer states (Healthy, Warning, Declining, Dormant, Hard Attrition), ML risk drivers.
5. **Customer Intelligence:** High-speed search, filtering, and 1-click 360-degree customer drawer.
6. **Customer Segmentation:** Behavioral archetypes validated across $k=2..8$ (Silhouette, Davies-Bouldin, Calinski-Harabasz).
7. **Leakage Intelligence:** Prime ₹5.52M missed cashback breakdown, high-ticket order leakage (≥ ₹5,000).
8. **Opportunity Center:** Master ranked recovery queue with Recoverability Proxy (Behavioral Feasibility Index).
9. **Next Best Action:** Prescriptive intervention playbooks with cost, expected value, and ROI.
10. **Strategy Lab:** Dynamic What-If campaign budget optimizer and conversion simulation.
11. **Experiment & Impact:** 3-Arm Randomized Controlled Trial (RCT) A/B test protocol.
12. **AI Discovered Insights:** 7 autonomous empirical discoveries with $p$-values, effect sizes, and 4-tier taxonomy filter.
13. **Model Explainability:** Multi-model benchmark tournament, 5-fold cross-validation, calibration curve, feature importances.
14. **Data Governance:** 5-dimension Data Quality Index (100.0% verified), audit lineage, referential integrity verification.
